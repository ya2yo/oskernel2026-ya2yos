
# 开发日志

## 第七周

本周主要完成了一些初始化工作。一开始原本打算从rcore开始改的，但对比往届参赛作品，发现如果从零开始构建难度较大，而且对于龙芯这种从未接触过的架构，感觉不好改，所以换成基于Tatlin这个。选择Tatlin主要是结构比较清晰，功能比较简单，上手难度低。

## 第八周

本周的主要工作是为TatlinOS实现网络模块。原有的net过于简单，所以为了实现net相关的syscall,本周主要学习了StarryOS的网络模块的设计，引用了StarryOS里面的net模块设计。为了支持net里面的各种操作和数据结构，在原来的内核基础上添加了poll相关的工具在utils文件夹下。同时，为了支持涉及到的异步操作，在task模块中新增了future功能。

## 4.27

修改了fd_table的位置，根据linux源码，fd_table应该由进程进行管理。为了避免，**规定之后的代码必须先获取task的锁再获取process的锁**。为了实现对fd_table成员的迁移，主要对task.rs内的clone_process()函数进行大幅度的修改，确保fd_table的复制和创建最后放入process的内部。

## 5.1

这几天主要进行syscall/fs模块的重构以及对fstruct.rs里面的结构体进行细微调整。

## 第九周

本周主要尝试将原先的工具链进行升级，同时基于OO的设计思想，又重新设计了fstruct.rs的内容。为了实现封装，fstable和fsinfo内部都有自己的锁进行管理，这样就避免还要在进程管理部分考虑两个文件相关的锁。同时本周也重新设计了全局ID分配器，原先的设计里面的循环可能会导致性能的损耗，所以重新设计，将分配和回收的主要逻辑放在id_allocator.rs里面去实现，实现RAII。

## 5.8

今天开始尝试针对ltp测试实现更多的功能，首先是net模块的实现，目前基本框架使用了StarryOS的，还有网络相关的驱动没完成。原来的virtio-drivers版本过低，尝试换成了0.7.5版本。

## 6.1

实现 `setresuid(147)` / `getresuid(148)` 系统调用，TCB 维护 real/effective/saved UID。同时统一将数据拷贝函数换为 `copy_from_user` 和 `copy_to_user`。详见 [problem/setresgid-syscall.md](./problem/setresgid-syscall.md)（同一模式）。

## 6.2

修复 LTP `creat04`（open 权限检查缺陷）：`create_file` 创建文件时增加父目录 owner/group/other 三级权限检查，`open()` 打开已有文件时增加写权限检查。修复过程中发现 root 判定使用 `user_id`（real uid）导致 `setresuid(-1,u,-1)` 后仍按 root 绕过——改为 `effective_uid`。详见 [problem/creat04-open-permission.md](./problem/creat04-open-permission.md)。

## 6.3

重构 lwext4_rust，实现 `sys_linkat`：删除重复的 `OsDirent` 定义，统一到 lwext4_rust；新增 `file_hardlink()` 通过 FFI 调用 `ext4_flink` 完成硬链接创建。syscall 层添加 AT_EMPTY_PATH 支持和参数校验。详见 [problem/linkat-hardlink-refactor.md](./problem/linkat-hardlink-refactor.md)。

修复 pthread_cancel_points 中线程信号帧栈检查错误（mmap 栈线程收到信号时 setup_frame 使用了主线程栈边界）和线程退出死锁（兄弟线程 futex 阻塞未唤醒）。同时移除 TCB 中冗余的 user_stack_top 字段，改为从 memory_set 动态查找。详见 [problem/thread-signal-stack-futex-deadlock](./problem/thread-signal-stack-futex-deadlock.md)。

## 6.4

LTP 300-500 测例推进：扩展 fcntl 处理，添加 sys_flock、sys_mknodat、xattr 基础实现，TCB 增加 exit_signal 字段。用 deepseek 辅助实现 mknodat 和 flock 的主体逻辑。修复 getsockopt 未拦截异常分配、锁未释放等 bug。创建 busybox 符号链接和 shell 脚本模拟 tst_sleep/tst_timeout_kill。
