# 文件系统

文件系统的主要目的是组织和存储数据。Hello_OS的文件系统总体上延续了Tatlin_OS的设计结构，同时新增了对网络模块的支持。

## 1. ext4_lw 轻量级文件系统适配层

### （1） 概述

ext4_lw 是本内核对 EXT4 物理文件系统的具体实现。它并不从零开始解析磁盘字节，而是通过封装外部库 lwext4_rust，将其复杂的功能通过适配器模式接入内核的 VFS 架构中。

**主要职责：**

- **硬件对接：** 实现磁盘驱动与文件系统库的数据交换。
- **接口转换：** 将 lwext4 的 C 风格接口转换为内核通用的 Inode 和 SuperBlock Trait。
- **路径解析：** 支持多级目录查找及符号链接（Symlink）处理。

### （2） 核心组件

整个模块主要分为三个部分：目录项，inode层，superblock层。
`sb` 模块中完成了`Ext4SuperBlock`的实现，同时，为了在内核中使用，该结构也需要实现内核规定的
`SuperBlock`trait,以及驱动trait`KernelDevOp`。

而`inode`模块主要实现了虚拟文件系统中`inode`结构，同时为把lwext4_rust放进内核，inode进
行一定的封装，形成`Ext4Inode`。同样，为了在OS内使用，整个结构体需要实现内核规定的`inode`trait。

`dirent`模块主要实现了文件系统中目录项的结构，整体较为简单。
