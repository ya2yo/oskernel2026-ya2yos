
# 开发日志

## 第七周

本周主要完成了一些初始化工作。一开始原本打算从rcore开始改的，但对比往届参赛作品，发现如果从零开始构建难度较大，而且对于龙芯这种从未接触过的架构，感觉不好改，所以换成基于Tatlin这个。选择Tatlin主要是Tatlin也是基于前年的TrustOS改的，而且结构比较清晰，功能比较简单，上手难度低。

## 第八周

本周的主要工作是为TatlinOS实现网络模块。原有的net过于简单，所以为了实现net相关的syscall,本周主要学习了StarryOS的网络模块的设计，引用了StarryOS里面的net模块设计。为了支持net里面的各种操作和数据结构，在原来的内核基础上添加了poll相关的工具在utils文件夹下。同时，为了支持涉及到的异步操作，在task模块中新增了future功能。出于本人能力所限，同时也为了内核尽可能简单，net需要的driver相关代码则参考了往届参赛作品Chronix的实现。

## 4.27

修改了fd_table的位置，根据linux源码，fd_table应该由进程进行管理。为了避免，**规定之后的代码必须先获取task的锁再获取process的锁**。为了实现对fd_table成员的迁移，主要对task.rs内的clone_process()函数进行大幅度的修改，确保fd_table的复制和创建最后放入process的内部。

## 5.1

这几天主要进行syscall/fs模块的重构以及对fstruct.rs里面的结构体进行细微调整。

## 第九周

本周主要尝试将原先的工具链进行升级，同时基于OO的设计思想，又重新设计了fstruct.rs的内容。为了实现封装，fstable和fsinfo内部都有自己的锁进行管理，这样就避免还要在进程管理部分考虑两个文件相关的锁。同时本周也重新设计了全局ID分配器，原先的设计里面的循环可能会导致性能的损耗，所以重新设计，将分配和回收的主要逻辑放在id_allocator.rs里面去实现，实现RAII。
