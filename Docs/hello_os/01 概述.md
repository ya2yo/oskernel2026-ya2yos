# Hello-OS

>- [Tatlin-OS文档](https://gitlab.eduxiji.net/T202510487995221/tatlin-os/-/tree/feat/final_2025/Docs)

## 介绍

本项目基于2025年全国大学生计算机系统能力大赛OS内核实现赛道二等奖参赛作品 TatlinOS 的 2025-tatlin 分支进行二次开发的。Hello OS 是本人出于学习操作系统底层编程知识，参加OS大赛而开发一个宏内核，整体实现较为简陋。本项目采用 Rust 作为开发语言，增量工作主要包括移植了 StarryOS 的网络模块，参考了 StarryOS 的项目结构，实现了更多的系统调用。
