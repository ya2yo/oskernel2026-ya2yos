修复 LTP `fcntl23`：`F_SETLEASE/F_GETLEASE` 不再固定返回 `EAGAIN/F_UNLCK`，新增按路径和 pid 管理的最小文件租约表，并在 close/exit 时清理租约。`make` 通过，LoongArch64 单跑 musl/glibc `fcntl23` 均 `TPASS`。详见 [problem/fcntl23-file-lease.md](./problem/fcntl23-file-lease.md)。

重构 `file_lock` 模块：将 `struct flock` ABI、POSIX record lock、file lease 和 BSD `flock(2)` 拆分为高内聚子模块，对外保持 `file_lock::...` 接口不变；LoongArch64 与 RISC-V 构建均通过。

完善 session ID 语义：`ProcessMeta` 新增独立 `sid` 字段，`fork/clone` 继承调用者的 `pgid/sid`，`getsid/setsid/setpgid` 不再混用 `pgid` 表示会话；LoongArch64 与 RISC-V 构建均通过。
