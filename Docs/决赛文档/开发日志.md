## 7.2

重构 PCB 与地址空间锁边界：将自带同步的 `MemorySet`、`SigTable`、`FdTable`、`FSInfo` 移出旧 `ProcessInner`，`MemorySet` 内部持有 `RwLock<MemorySetInner>`，`personality` 并入 `ProcessMeta`。

继续重构 PCB 访问接口：移除 `Process::inner_lock()` 和 `ProcessResources` 兼容层，调用点直接通过 `Process` 访问地址空间、信号表、fd 表和 fs 上下文；`make` 通过，QEMU 运行验证本轮未完成。

新增 `ResourceSlot<T>` 资源槽抽象，将 `Process.memory_set` 与 `Process.sig_table` 改为私有可替换槽位，明确区分资源内部同步和进程资源指针替换；`make` 通过，LoongArch64 `make run` 基础测试跑到 `shutdown!`。

继续收敛 PCB 地址空间接口：删除 `get_locked_memory_set_read/write()` 兼容方法，调用点统一使用 `memory_set_arc()`；`make` 通过，LoongArch64 `make run` 基础测试跑到 `shutdown!`。

收敛 pipe 文件描述符分类：`pipe2()` 分配的匿名 pipe 统一存入 `FileClass::Pipe`，`vmsplice` 改为通过 pipe 类型入口校验和写入；默认 LoongArch64 `make` 通过。

实现 `splice(2)` 兼容搬运路径：支持 regular file 与 pipe、pipe 与 regular file、pipe 与 pipe 之间通过内核缓冲区传输，补齐 offset 写回、pipe offset `ESPIPE`、`O_APPEND` 输出 `EINVAL`、`SPLICE_F_NONBLOCK` 基础语义；LoongArch64/RISC-V 构建通过，LoongArch64 `splice01` musl/glibc 均 `TPASS`。详见 problem/。

优化 pipe 内部缓冲结构：将 `PipeRingBuffer` 从字节环改为 `PipeBuf` 片段队列，`splice(pipe, pipe)` 走片段引用移动，`tee()` 走片段引用复制；默认 LoongArch64 `make` 通过。当前 `initproc` 中的 `splice05` 仍暴露 socket splice `ENOTCONN` 语义缺口，需后续单独处理。

接入文件页面缓存到 `MAP_SHARED` mmap 与 `splice(file, pipe)`：共享文件缺页改由 `FILE_PAGE_CACHE` 提供 `FrameTracker`，`PipeBuf` 支持挂载 `FilePage`，普通文件到 pipe 的 `splice` 走缓存页引用 fast path；默认 LoongArch64 `make` 通过，当前 `splice09` 入口因内核版本要求 `TCONF/skipped` 并跑到 `shutdown!`。
